# Internet

**Where to find it:** Internet & safety > Internet.

See how the connection is doing, and fix it if it isn't. Most of the page only looks; the fixes ask before they change anything.

## Your connection

A quick summary of how this PC is connected (**Refresh** re-reads it):

- **Connected by** - Wi-Fi, network cable, or not connected.
- **Wi-Fi name** and **Wi-Fi signal** - shown only on Wi-Fi, with the signal described in words.
- **This computer's address** - the PC's address on your home network.
- **Your router** - the address of the box that connects you to the internet.
- **Name servers (DNS)** - the services that turn website names into addresses.

## Fix my internet

**Check my internet** tests each part of the connection one at a time and tells you what it finds. The four steps are **Network connection**, **Your router**, **Website names** and **The internet**, each showing a plain result (for example "Connected" or "Your router answers"). If something is wrong, Porchlight suggests one or more fix buttons, such as:

- **Clear saved website addresses**,
- **Get a fresh connection**,
- **Switch the network connection off and on** (needs administrator rights),
- or opening the Windows network settings.

Before it changes anything it asks **Yes, continue** / **Cancel**, then shows "Working on it..." and a result message.

## Speed test

**Start speed test** (and **Stop**) measures **Download**, **Upload** and **Delay** (how long a reply takes) and gives a plain verdict on whether that is fine. It takes about 10 seconds and sends data to and from Cloudflare (speed.cloudflare.com), so it uses some of your internet allowance. The time of the last test is shown under the results.

## Programs using the internet

A read-only list of which programs are talking over the internet right now, with a count of connections for each. It refreshes every few seconds while the page is open.
