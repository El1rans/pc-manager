# Health check

**Where to find it:** Tune-up > Health check.

See whether the PC is in good shape, and fix common problems. The page checks automatically when you open it; **Check again** (top right) re-runs everything.

## What's on the page

- **Administrator banner** - shown when Porchlight is not running as administrator. Repairing Windows files and creating a restore point need admin rights (use **Restart as admin** in the left menu).

### Disk health

Reads the disks' built-in health reports and gives a plain verdict: **Healthy**, **Warning - back up your files soon**, or **Unknown**, with the reasons underneath (for example a heavily worn SSD). An extra warning line appears if the disk itself predicts a failure.

### Windows repair

Checks Windows' own files for damage and repairs them. Try it if Windows is slow, crashes or acts strangely.

- **Check and repair Windows files** - runs the check; a progress bar and step line show where it is.
- **Run deeper repair** - only offered if the first check could not fix everything.
- **Result message**, and a **Details** section holding the technical log.

### Restore point

A restore point is a safety snapshot of Windows that it can go back to if a change goes wrong. Your own files are not touched.

- **Create a restore point** - makes one now (needs administrator rights, and System Protection turned on).
- **Open System Protection** - opens the Windows settings where it is switched on.
- **Most recent restore points** - a list with when each was made.

### Recent problems

Recent crashes and serious errors from the Windows event log, each with when it last happened and, where available, some advice. Shows a green "no problems" message when there is nothing to report.

### Battery

Only appears on laptops and tablets. Shows a verdict on battery wear - Good, Worn or Very worn (how much of its original charge it still holds), or Unknown if the battery does not report it - with a short detail line.
