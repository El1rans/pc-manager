# Free up space

**Where to find it:** Tune-up > Free up space. The Dashboard's **Free up space** button (shown when a drive is nearly full) also opens it.

Clears out things the PC no longer needs, and helps you find what is filling a drive. Your own files are never deleted without you choosing them, and anything you remove from your folders goes to the Recycle Bin first.

## Top of the page

- **Administrator banner** - shown when Porchlight is not running as administrator. Cleaning some Windows locations needs admin rights.
- **System drive card** - how full the Windows drive is (bar plus free/total space), the total freed so far this session, and a link **Open Windows Storage settings**.

## Clean up

Safe-to-remove leftovers, each with its size and a tick box:

- **Temporary files** and **Windows temporary files** - scraps programs and Windows leave behind.
- **Browser caches** - saved copies of web pages (bookmarks, history and passwords are not touched; close the browser first).
- **Picture previews** - small saved previews of pictures and videos, rebuilt by Windows when needed.
- **Crash reports and dumps** - technical reports saved after a crash.
- **Windows Update leftovers** - update files Windows has already installed.
- **Windows update sharing cache** - copies of updates Windows shares with other PCs; downloaded again if needed.
- **Recycle Bin** - permanently empties it; these files cannot be brought back.

Buttons: **Scan again** re-measures everything; **Clean up** removes what is ticked (with a **Stop** button while it runs, a progress line, and a result message saying how much was freed). A running total of the ticked size is shown above the button.

## What's using space?

Pick a drive or folder with **Choose a folder...** and press **Scan** (or **Stop**). It shows the biggest folders and files inside, with sizes and percentages, and a breadcrumb trail so you can go back up. Each row can be opened, **Show in folder**, or moved to the Recycle Bin. It only looks; nothing changes unless you choose it. A note tells you if some places could not be read.

## Duplicate files

**Find duplicates** looks for identical copies of big files (1 MB or more) in your own folders. Each set shows the copies with their dates, marks the newest, and always keeps one copy ("This copy will stay"). **Keep newest** (per set) or **Keep newest in every set** tick the older ones for you, **Clear ticks** unticks everything, and **Move ticked files to the Recycle Bin** removes them.

## Big files

The largest files in your own folders, each with **Show in folder** and **Move to Recycle Bin**.

## Old downloads

Installers and archives in your Downloads folder that you have not touched for over 30 days, with the same buttons.

## Large apps

The programs taking the most room. **Uninstall...** opens the program's own uninstaller; for things Porchlight cannot uninstall, **Open Installed apps** opens the Windows list instead. For safety, uninstalling from Porchlight is turned off while it runs as administrator. **Show all** expands the list.
